# 星途AI—星途中转站参考视频与参考音频统一协议 v2.2

> 本候选稿已被 `docs/星途AI下游视频音频v2.2最终对接说明.md` 取代；下游只执行最终对接说明。

状态：候选冻结稿，生产提交默认关闭。合同版本：`xtai-video-billing-v2.2`。冻结日期：2026-08-13。

本文评审并修改下游提供的《XTAI_VIDEO_REFERENCE_VIDEO_PROTOCOL_V22(1).md》。它是候选建议，不是中转站必须原样接受的合同。统一协议以方舟/Seedance 官方能力为产品上限，以各上游真实接口验证结果为可用路由交集。

- 不含参考视频/音频的新任务继续使用 `xtai-video-billing-v2.1`。
- v2.1 收到 `video`、`videos`、`audio`、`audios`、`reference_videos` 或 `reference_audios`，必须在报价、冻结、建任务和上游调用前拒绝。
- v2.2 唯一规范字段为 `reference_videos` 与 `reference_audios`，并使用与 `request_id` 相同的 `Idempotency-Key`。
- 参考视频、参考音频、二者组合使用三个独立且默认关闭的开关。
- 能力目录区分 `supported`（官方模型支持）与 `available`（至少一条中转路由已验证）。官方已确认最多9图、3视频、3音频且可灵活组合，最长生成15秒；路由未验证时显示 `supported=true, available=false`，不能创建付费任务。
- 当前统一基础格式支持 MP3/WAV 参考音频与 MP4 参考视频；后续官方确认更多格式时通过能力目录增加，不改变下游字段。
- 签名 URL 不进入幂等指纹，不持久化，不写入普通日志或 Webhook；指纹使用有序 SHA-256 与媒体元数据。
- `generate_audio` 是输出音轨开关，`reference_audios` 是输入参考，两者独立，不可静默改变。
- 预冻结统一为方舟对应官方计费档 ×1.5：含参考视频使用官方“含视频输入”档（标准/Fast/Mini 当前分别为28/22/14元每百万tokens），不含参考视频使用官方“无视频输入”档（46/37/23元每百万tokens）；音频不另猜附加倍率。最终应收保持为可信单任务上游实际净扣费 ×1.5，多退少补。
- 在书面能力、价格、素材注册、结算、私有 TOS、测试 Webhook、无费用测试及用户另行批准的一条付费冒烟全部完成前，不得启用生产 v2.2。

## 当前实现状态

中转站已识别合同版本、发布失败关闭的能力/价格状态、校验候选 MP4/MP3 元数据、生成不含 URL 的稳定摘要，并保证默认关闭时不创建任务、不冻结、不调用上游。

上游字段映射、媒体注册与安全抓取、精确路由能力以及付费提交尚未启用；这些项目必须以每个上游的真实请求/响应样例或无费用探测为依据，不猜测字段。

## 仍需上游逐项提供

1. 接受 v2.2 合同及两个规范字段的书面确认。
2. 按稳定模型、分辨率分别列出仅视频、仅音频、视频+音频能力。
3. 视频数量、大小、单段/总时长、MIME、编码、宽高上下限。
4. 音频数量、大小、单段/总时长、MIME、编码、采样率、声道、是否要求非音频输入。
5. 图片/视频/音频组合、总素材数以及与 `generate_audio=true` 的组合边界。
6. 素材注册接口、成功 ID、顺序与 SHA 绑定、幂等和丢响应后的查询方式。
7. 三种输入价格档、修订和证据来源。
8. 单任务实际净扣费证据及内容安全、隐私、素材失效、受理不确定的错误映射。
9. 三组不含秘密的最小请求、查询、Webhook、结算与失败样例。

完整字段、错误码、上线门禁与双方职责以收到的候选冻结稿原文为准；本文是仓库内的实施状态说明，不缩减原协议约束。
