# Image-2.5 接入说明

统一模型名：`gpt-image-2.5`。接口：`POST https://api.aixingtuyun.com/v1/images/generations`。使用本站API密钥，令牌需有“图”分组和该模型权限。

| size | 像素 | 售价（沿用本站人民币额度换算） | 可用上游 |
|---|---|---:|---|
| `1024x1024` | 1K方图 | 0.0375元/张 | Rolldek优先、寒鹤备用 |
| `2048x2048` | 2K方图 | 0.075元/张 | 寒鹤 |
| `4096x4096` | 4K方图 | 0.15元/张 | 寒鹤 |

```json
{
  "model": "gpt-image-2.5",
  "prompt": "一只蓝色杯子，白色背景",
  "size": "2048x2048",
  "n": 1,
  "response_format": "b64_json"
}
```

请求头必须为 `Content-Type: application/json`，并携带 `Authorization: Bearer <本站API密钥>`。

初版仅开放已验证的文生图、单张、上述三个方形尺寸。`quality`省略或`auto`；不接受未验证的高品质档、多图、编辑、参考图、其他比例或分辨率写法。无size默认1K；明确指定size最稳妥。

按分辨率预扣与结算。`/api/pricing`的单值model_price是1K基准价，实际计费以billing_mode=tiered_expr和对应表达式为准，不要把1K价用于全部分辨率。

供应商型号与供应商称谓，不代表本站验证了OpenAI官方模型身份。海纳sunburst/flare本次均返回错误，不开放、不自动映射到本型号。既有Image-2/Banana/视频不变。
