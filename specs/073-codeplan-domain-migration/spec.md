# Code Plan 域名迁移规格

## 目标

将因注册局 `server hold` 而停止解析的 Code Plan 原域名迁移到已验证的新主域名，并使文字、图片、余额与调用监控使用同一权威来源。

## 要求

- 主域名固定为 `https://oh-code.me`。
- 候选备用域名只记录验证结果，不建立多个共享账号的并发渠道。
- 写入前必须验证 DNS、TLS、系统身份、文字密钥模型目录和账号登录/余额。
- 图片保留下游统一模型 `gpt-image-2`；若当前密钥分组无模型资格，则迁移地址但保持停用，不能让用户继续收到 503。
- 文字渠道只启用密钥目录明确返回的本站模型：`gpt-5.5`、`gpt-5.6-sol`、`gpt-5.6-terra`。
- 修改 PostgreSQL 与监控 JSON 前创建可恢复备份；精确校验渠道 38/39 的身份。
- 修改后重启 NewAPI 以刷新缓存，运行余额采集并进行多轮只读复核。

## 安全边界

- API Key、账号密码与监控凭据不得进入仓库、日志或聊天。
- 图片验证不得创建付费生成任务；无资格时失败关闭。
- 文字允许一个最小实际请求作为恢复门禁。
