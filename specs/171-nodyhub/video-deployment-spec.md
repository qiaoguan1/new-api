# NodyHub video production enablement

User explicitly authorized skipping Grok image and deploying all seven proven video models. This extends the existing authenticated XingTu video gateway and v2.1/v2.2 task protocol, not a new independent account balance ledger. Flare/Sunburst image channel57 and all old channels stay unchanged.

Public model IDs use the seven exact tested upstream IDs. Only tested duration/resolution/16:9 text generation is enabled. The seven existing sample MP4s were parsed in memory and all have both vide and soun tracks; native/default audio is retained and generate_audio=true is required. No unverified mute toggle or reference assets are advertised.

Reservation uses a distinct verified-source-cost basis, never an Ark label. Private verified cost×1.5 gives the reserve quote; successful jobs wait for an exact authenticated terminal Nody task quota×1.5(CNY conversion), then charge actual CNY cost×1.5 with existing idempotent settlement/outbox. Failed jobs require matching refund evidence. Unknown Nody submissions are never automatically replayed; Nody has not established idempotency support.

Existing Seedance catalog objects and Ark prices are protected unchanged; only catalog revision and seven new models are additive. Historical routing tests use their fixed August fixture instead of mutable production priorities; a separate test compares all preexisting production models against the live pre-change fixture.

Deployment gates: all151 regression tests; real read-only cost parsing against existing successful and failed tasks; image digest verification; dark canary full task/actual billing/result delivery; production SQLite/config/container backup; no active tasks at controlled cutover; public capability/price/submit/replay/query/content and old model regression.

Important boundary: existing shared-service gateway reports settlement to authorized downstream software, which owns its own users/accounting. This does not claim ordinary NewAPI bearer-token wallet support or change downstream billing policy. No NewAPI wallet SQL writes are introduced.
