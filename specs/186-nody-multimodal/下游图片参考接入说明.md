# 星途视频图片参考接入说明（候选版本，生产验收前不视为已开放）

当前改造不更换用户密钥，不修改既有文生视频调用。
主地址：`https://api.aixingtuyun.com`。

## 先读取实时能力

使用用户自己的正常API密钥，读取 `GET /v1/capabilities` 和
`GET /v1/video-prices`，带 `X-XingTu-Contract-Version: xtai-video-billing-v2.2`。

对所选模型检查 `image_reference.available`，从
`image_reference.specifications` 选择完整规格；价格接口的
`image_reference_pricing.models` 必须存在相同模型、模式、图片数量、分辨率和时长。
不能用模型的通用分辨率列表与模式列表任意拼接。

目前有上游文档依据的只有三款Grok图片参考模式。Wan3、Wan3Prime、FLUX3、
OmniFlash，以及这批模型的首尾帧、参考视频、参考音频，仍不得因本改造自动标为支持。
生产只公布实测结果与真实账单都完成的精确规格，未公布的组合不要提交。

## 提交单图参考

```http
POST /v1/videos
Authorization: Bearer <用户自己的API密钥>
X-XingTu-Contract-Version: xtai-video-billing-v2.2
Content-Type: application/json
Idempotency-Key: image-ref-order-001
```

```json
{
  "request_id": "image-ref-order-001",
  "model": "grok-imagine-video-official",
  "prompt": "让图片中的小球缓慢移动，保留自然声音。",
  "resolution": "480p",
  "duration": 1,
  "aspect_ratio": "16:9",
  "generate_audio": true,
  "mode": "reference",
  "images": ["https://upload.aixingtuyun.com/media/<已上传素材文件>"],
  "image_roles": ["reference"],
  "image_identities": ["<该图片真实文件字节的64位小写SHA-256>"]
}
```

- `reference` 表示一张图片参考，不承诺严格首帧锁定。
- `all_reference` 表示多张图片参考；数量必须与实时规格相符。
- 三个图片数组必须一一对应，顺序有意义；不能按两张图片自动推断首尾帧。
- 素材须来自已批准域名，使用可被上游读取的HTTPS地址；PNG/JPEG，每张不超过10MiB。
- 本批验收限定16:9输入图片；输出实际像素尺寸以最终视频为准，不把上游分辨率档位当成固定长宽。
- SHA-256必须计算真实文件字节，不能只计算URL字符串；中转会下载并核对内容、格式和尺寸。
- 图片不通过安全校验时不会预扣或提交上游。若排队后素材过期，明确未创建任务的首次拒绝会退回预扣。

## 查询、结算和重复请求

仍用 `GET /v1/videos/{id}` 查询，结果由同一有效用户密钥下载。
以 `billing.status=settled`、`result_delivery=ready` 为可交付条件。
最终按上游真实费用×1.5结算，预扣与最终费用不同会多退少补。

同一request_id、模式、规格、图片角色及内容SHA身份只能创建一个任务。
仅更换同一内容的签名URL会复用原任务，不会修改已冻结的旧URL。
如果任务已经创建，不要因为超时换request_id重新生成。提交结果不明的任务继续查询原任务，
不能凭一次后续拒绝认定上游没有扣费。

配置撤回只停止新请求，已经接受的任务仍可复用和查询其冻结记录。
前端应根据实时目录显示图生/图片参考选项；不要仅硬编码七个模型名后统一打开所有模式。
