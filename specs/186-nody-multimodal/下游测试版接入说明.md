| 模型ID | 素材候选 | 模式与限制 |
|---|---|---|
| wan3.0-video / wan3.0-video-prime | 图片、视频、音频 | 首帧、尾帧、首尾帧、单/多素材参考；最多10图、5视频、5音频 |
| omni-flash | 图片、视频 | 图片数量0/1/3，最多1视频；无音频参考；视频输入显式输出4–30秒，文生/仅图片4/6/8/10秒 |

## 目录和价格

使用现有普通API密钥，主地址 `https://api.aixingtuyun.com`。

- `GET /v1/models`：模型可见性仍受原密钥权限、分组、IP和白名单约束，不修改密钥。
- `GET /v1/capabilities`：`operator_testing.available=true` 且规则注明 `unverified` 才是本次手测范围。
- `GET /v1/video-prices`：旧文生行、六个Grok图片精确行保留。响应顶层的 `operator_testing.rules` 是估算规则，不是成功实测规格（不在 `pricing` 对象内）。
- `/api/pricing` 模型广场同时标注手测规则与素材能力。

请求带 `Authorization: Bearer <用户自己的密钥>` 与 `X-XingTu-Contract-Version: xtai-video-billing-v2.2`。不要把通用文生价格拿来计算新素材模式，也不要把 `unverified` 改显示为“已验证”。

## 提交

`POST /v1/videos`，`Idempotency-Key` 与 `request_id` 完全相同。新宽规格文生须显式传 `mode:"text"`。

首尾帧示意（地址与哈希必须换成真实素材）：

```json
{
  "model": "wan3.0-video",
  "mode": "first_last_frame",
  "prompt": "从首帧自然过渡到尾帧",
  "resolution": "480p",
  "duration": 2,
  "aspect_ratio": "16:9",
  "generate_audio": true,
  "request_id": "your-unique-request-id",
  "images": ["https://upload.aixingtuyun.com/first.png", "https://upload.aixingtuyun.com/last.png"],
  "image_roles": ["first", "last"],
  "image_identities": ["<首帧真实SHA256>", "<尾帧真实SHA256>"]
}
```

普通图参考使用 `reference`（一项素材）或 `all_reference`（至少两项），图片角色 `reference`。视频放 `reference_videos`，角色 `reference_video`，需 `url/sha256/size_bytes/duration_seconds/mime_type/width_pixels/height_pixels`。音频放 `reference_audios`，角色 `reference_audio`，需再提供 `codec/sample_rate_hz/channels`。时长为六位小数字符串，必须与真实文件探测结果一致。
