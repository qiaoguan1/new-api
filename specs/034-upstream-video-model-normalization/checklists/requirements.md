# Requirements Checklist

- [x] Scope is limited to upstream video catalog governance.
- [x] Stable models and resolution dimensions match the relay protocol.
- [x] Frequent upstream renames and multiple upstreams are addressed.
- [x] Automatic matching is deterministic and fail closed.
- [x] AI suggestions cannot self-approve or publish.
- [x] Rules are versioned, editable, auditable, and hot-loadable.
- [x] Health, route, trusted price, mapping, and policy gates are explicit.
- [x] Unknown names and missing cost evidence preserve production state.
- [x] Public output excludes upstream and commercial internals.
- [x] Tests, production dry-run, backup, rollback, and ten-round verification are required.
