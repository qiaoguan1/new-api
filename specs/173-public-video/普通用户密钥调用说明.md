# 普通用户密钥调用说明

2026-09-24，星途中转站已开放。主地址：`https://api.aixingtuyun.com`。

用户使用自己在中转站创建的正常 API Key，不再需要视频专用服务密钥。正常账户、未停用/未过期密钥可用；账户及有限额密钥需要足够预扣额度。用户自行设置的模型白名单、IP限制及分组授权仍保留，不会被清空。

## 视频提交

```http
POST /v1/videos
Authorization: Bearer <用户自己的API Key>
Content-Type: application/json
Idempotency-Key: video-my-order-001
```

```json
{
  "request_id": "video-my-order-001",
  "model": "grok-imagine-video-official",
  "prompt": "一个蓝色小球在桌面缓慢滚动，保留自然滚动声。",
  "resolution": "480p",
  "duration": 1,
  "aspect_ratio": "16:9",
  "generate_audio": true
}
```

返回HTTP202以及 `id=vjob_...`。`request_id` 与 `Idempotency-Key` 同时填写时必须一致。同一用户、同一请求标识与相同内容重试返回原任务，不会多扣；内容不同返回409。建议始终填写唯一请求标识，超时不要换标识重发。

## 状态、费用和结果

用同一账户下有权访问该模型的有效密钥：

```http
GET /v1/videos/{id}
Authorization: Bearer <用户自己的API Key>
```

- `status=queued/running`：排队或生成中。
- `billing.status=reserved`：账户和密钥已预扣。
- 生成完成但未拿到账单：`settlement_pending`，不能把预估费用当实际结算。
- `status=succeeded`、`billing.status=settled`、`result_delivery=ready`：可交付。
- `billing.charged_amount`：最终人民币费用字符串。
- `billing.refund_amount / supplement_amount`：退款或补扣金额。
- `result_url`：视频地址，下载同样携带用户自己的密钥；不公开裸上游链接。

最终按上游准确实际成本×1.5多退少补。账户、密钥、消费日志与最终结算凭证在数据库中一次性提交，不依赖下游持续轮询才能扣费。当前本站1元面值对应500000内部额度，与页面显示的美元汇率以及上游额度兑换不是同一概念。单次请求保留自己的换算依据，不重算历史账单。

普通用户任务彼此隔离：其他用户查状态或下载返回404。已经预扣后密钥额度耗尽，仍可查询已支付任务；停用/过期或账户禁用的密钥不继续放行，可使用同账户其他有效且有模型权限的密钥。

普通用户任务不会发送到星途AI软件的专属回调。星途AI原服务密钥、协议与签名回调保持原有行为。下游自行决定向其用户收多少钱，不由本次改造更改。

